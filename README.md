# 🏏 Cricket Tournament Management System

A database management system designed to manage cricket tournaments, teams, players, venues, matches, and ball-by-ball match records using SQL.

## 📌 Project Overview

The Cricket Tournament Management System provides a structured database for organizing and managing cricket tournament information. It stores details about tournaments, teams, players, venues, matches, and individual ball-by-ball records.

## 🎯 Objectives

- Manage cricket tournaments efficiently
- Store team and player information
- Manage cricket venues and stadiums
- Record match details
- Maintain ball-by-ball match records
- Establish relationships between different entities
- Apply database normalization principles

## 🗃️ Main Database Entities

- **Tournament**
- **Team**
- **Player**
- **Venue**
- **Match**
- **Ball-by-Ball Record**

## 📊 Project Data

- 15 Venues
- 20 Teams from different cities of Pakistan
- 15 Tournaments
- 50 Players
- 40 Matches
- 120 Ball-by-Ball Records

## 👤 Player Roles

Players are categorized into:

- Batsman
- Bowler
- All-Rounder
- Wicketkeeper
